# HRNet

An employee management dashboard for creating, viewing, and searching employee records.

## Features

- Employee creation form with validated fields (name, date of birth, start date, department, address)
- Custom date picker and select components (from [doom-ui](https://github.com/Zansuken/doom-ui))
- Searchable, sortable, paginated data table
- Client-side state persistence

## Tech

React · TypeScript · Vite · Tailwind CSS · [doom-ui](https://github.com/Zansuken/doom-ui)

## Run locally

```bash
git clone https://github.com/Zansuken/HRNet.git
cd HRNet
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
